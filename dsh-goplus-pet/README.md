# dsh-goplus-pet 🐾


一只住在 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) Web 界面里的GoPlus吉祥物桌面宠物。

---

## 快速开始（安装插件）

```sh
git clone https://github.com/melonux/dsh-goplus-pet
cd dsh-goplus-pet
dsh plugin --profile web add file:./dsh-goplus-pet
```

重启 `dsh web`，宠物出现在右下角。
